# Semana 25 — Guía del Capstone

> Esta semana no tiene teoría nueva. Es la integración de todas las semanas anteriores.

## Checklist de preparación

- [ ] Elegir una de las 4 opciones (A, B, C, D)
- [ ] Definir el alcance mínimo viable
- [ ] Diseñar la API pública antes de implementar
- [ ] Crear el proyecto con scaffolding limpio
- [ ] Implementar tests desde el principio (TDD opcional)
- [ ] Documentar con `///` cada ítem público
- [ ] Verificar integración con el ecosistema externo
- [ ] `cargo clippy -- -D warnings`
- [ ] `cargo fmt --check`
- [ ] `cargo audit`
