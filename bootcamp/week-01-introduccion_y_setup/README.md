## 🎯 Objetivos de Aprendizaje

Al finalizar esta semana, el estudiante será capaz de:

1. **Comprender** qué es Rust y por qué es relevante en el desarrollo moderno
2. **Configurar** un entorno de desarrollo funcional con Docker
3. **Utilizar** Cargo para crear y gestionar proyectos
4. **Escribir** y ejecutar un programa básico en Rust
5. **Identificar** la estructura de un proyecto Rust

## 🔑 Conceptos Clave

```
┌─────────────────────────────────────────────────────────────┐
│  CONCEPTOS SEMANA 01                                        │
├─────────────────────────────────────────────────────────────┤
│  • Rust          - Lenguaje de sistemas seguro y rápido     │
│  • Cargo         - Gestor de paquetes y build system        │
│  • Crate         - Unidad de compilación (librería/binario) │
│  • rustc         - Compilador de Rust                       │
│  • Cargo.toml    - Archivo de configuración del proyecto    │
│  • src/main.rs   - Punto de entrada del programa            │
│  • fn main()     - Función principal                        │
│  • println!      - Macro para imprimir en consola           │
└─────────────────────────────────────────────────────────────┘
```
